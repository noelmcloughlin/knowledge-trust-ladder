# Overview

Participation in this repository is covered by the Contributor Covenant Code of Conduct, version 2.1, the same one the sibling LOKF repositories use. `CONTRIBUTING.md` points to it. The text is the standard covenant, adapted for this project and kept at `CODE_OF_CONDUCT.md`.

# What it asks

Members, contributors and leaders pledge to make participation a harassment-free experience for everyone, and to act in ways that contribute to an open, welcoming, diverse, inclusive and healthy community. The file lists the behaviour that counts toward that and the behaviour that is unacceptable, names the community leaders' responsibilities for clarifying and enforcing the standards, and says how to report unacceptable behaviour and what enforcement looks like.
