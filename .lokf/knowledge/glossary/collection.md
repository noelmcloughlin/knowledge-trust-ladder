# Overview

The README's opening paragraph, which the architecture page repeats, says that Knowledge Trust Ladder keeps any repository's scattered knowledge as a **collection**: catalogued, authenticated and explained, with the trust in every claim left visible.

The architecture page uses the museum word the same way. The [registrar](registrar.md) keeps each [accession](accession.md), an item added to the collection, documented, with its provenance filed. The [docent](docent.md) is the role the poem leaves implicit, because the collection exists for its visitors.
