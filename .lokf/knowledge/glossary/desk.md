# Overview

The README uses *desk* in its library and museum terms, for the place where a role does its work with the bundle. It says which program is the registrar at each one. At the librarian's desk the registrar is `knowledge-apply.sh`, called *the pen* because the librarian writes the bundle only through it. At the reader's desk and the curator's it is `knowledge-report.sh`, which computes each trust label and the bundle's health line, so that neither is a model's arithmetic.

In Obsidian there is no CI, so two optional plugins, KTL Registrar and KTL Curator, do the registrar's work inside the editor.
