# ktl-prose, the copy editor

This page is for anyone whose bundle reads as if an agent wrote it.

`ktl-prose` is the **librarian**'s copy editor, and it is optional. It rewords what an agent wrote, in plain English, before a person confirms it. It changes the wording and never a fact.

| | |
| --- | --- |
| **Played by** | the [`ktl-prose`](../../skills/ktl-prose/SKILL.md) skill, an agent |
| **Runs** | between the [librarian](librarian.md) and the [curator](curator.md) |
| **Writes** | the body of a concept an agent wrote and no person confirmed, and one line in `log.md` |
| **Never** | changes frontmatter, or a concept a person wrote or confirmed |
| **Checked by** | its own script, which compares code, links and numbers with the earlier text |
| **Line of defence** | first, on the maker's side ([three-lines.md](../three-lines.md)) |

## Ask it

- "Give the bundle a plain-English pass."
- "Which concepts read as if an agent wrote them?"
- "Write a version of this page for readers aged 13 to 18."
