# knowledge-trust-ladder

This name installs [`ktl`](https://pypi.org/project/ktl/), the package that carries the six Knowledge Trust Ladder (KTL) agent skills and the command that installs them. It holds no code of its own. Each release depends on `ktl` at the same version, and its `knowledge-trust-ladder` command is `ktl` under the repository's name:

```bash
uvx knowledge-trust-ladder skills install --scope user
```

[The KTL site](https://w3id.org/ktl/) says what each skill does, and [the install page](https://w3id.org/ktl/docs/install/) gives every route.
