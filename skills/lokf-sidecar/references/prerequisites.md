# Prerequisites - what the preflight's lines mean, and who fixes each

`.lokf/scripts/knowledge-preflight.sh` prints one line per thing a skill depends on, in the words of the tools it checked. Not everyone who runs a skill can act on those words: a curator is chosen for knowing the subject, not the repository, and a reader asking the docent may know neither. This page is the translation. Each row says what the line means, what it stops, who normally puts it right, and what to send that person. **You** means the person at the keyboard; **the maintainer** means whoever set the repository up, or the team's engineer; **an administrator** means someone with the forge's settings.

When a skill's preflight names something the person cannot fix themselves, write them a short request note from this table - addressed to the maintainer or administrator, not to the person - with the preflight line quoted as printed, the row's request, and what the person can still do in the meantime. Being signed in to GitHub in a browser is not the same as this machine being signed in: the note should say so when the line is `identity`, because that is the usual confusion.

| Line | It means | It stops | Who | What to send them |
| --- | --- | --- | --- | --- |
| `host` | The computer, its shell, and whether it can compute a digest or run Python. | Nothing by itself; a missing digest tool only affects the curator's sampling step. | you, or the maintainer | "The preflight says this machine has no `sha256sum`; on a Mac, `shasum -a 256` is the substitute, or install coreutils." |
| `bundle` | Whether the knowledge folder exists, how many concepts it holds, and whether the `knowledge_bundle` shortcut beside it is in place. | Missing: every skill but the sidecar. | the maintainer | "There is no `.lokf/knowledge` here yet. Please run the lokf-sidecar skill once in this repository, or tell me which folder holds the bundle." |
| `sync` | The folder lives in OneDrive, Dropbox, Drive or iCloud. | Nothing; a warning that links and conflict copies behave differently there. | you | Nothing to send. Delete a "conflicted copy" file after reading it; conventions rule 7 will name it. |
| `git` | Whether the folder is under git, whether the bundle is committed, and whether line endings are pinned. | No git: pull requests, signed-commit checks and the scheduled loop. | the maintainer | "The preflight reports `<line>`. Please confirm whether this bundle is meant to be under git, and if so add `.lokf/.gitattributes` from the sidecar's templates." |
| `endings` | Some bundle files use Windows line endings or start with a byte order mark. | Nothing here; other tools may misread them. | you, or the maintainer | "Some bundle files have CRLF endings or a BOM. Please save them as UTF-8 without BOM, or add the sidecar's `.gitattributes`." |
| `forge` | Which hosting service the repository is on, and whether the registrar gate workflow is present. | No gate: nothing checks a confirmation after it is recorded. | the maintainer | "The repository has no `knowledge-registrar.yaml`. Please lay it down with lokf-sidecar Step 5, or port it per the sidecar's portability page if we are not on GitHub." |
| `identity` | Whether this machine is signed in to the forge, so that a confirmation can carry the person's account name. | Confirm and Correct now in the curator; naming the asker in the docent's feedback. | you, with the maintainer's help | "I need this machine signed in to GitHub from the terminal so my confirmations are recorded under my account: install the GitHub CLI and run `gh auth login` as me (GitLab: `glab auth login`). My browser login does not cover this." |
| `signing` | Whether commits made here are signed, and with which kind of key. | The gate rejects a curation pull request the same person opens. | you, with the maintainer's help | "Please set up commit signing for me on this machine - the steps are in lokf-agent-skills `docs/signing-commits.md` - and register the public key on my forge account as a signing key." |
| `curators` | Whether the repository keeps a public key per curator for the forge-free gate, and whether yours is among them. | Confirmations you sign fail that gate until your key is on file. | an administrator | "Please add my public signing key to `.lokf/curators/<my login>.asc` (GPG) or `.pub` (SSH) in its own pull request. `docs/signing-commits.md` in lokf-agent-skills says how to export it." |
| `toolkit` | Whether `uv` and the `lokf` toolkit are installed, and at which version. | Validation, conversion and queries; a bundle can still be read and edited. | you, or the maintainer | "Please install `uv` (docs.astral.sh/uv) and run `just lokf-install` in `.lokf/`, so the bundle can be validated." |
| `just` | Whether the `just` command runner is present. | Nothing; `uvx --from rust-just just` does the same. | you | Nothing to send. |
| `skills` | Which of the four skills are installed, and whether two installed copies differ. | Nothing; a stale copy may give an older answer. | the maintainer | "The preflight found two copies of `<skill>` that differ. Please reinstall the LOKF skills from one release, or remove the stale copy." |
| `copies` | Whether the scripts and workflows the sidecar laid down still match their templates. | Nothing; a drifted copy may miss a later fix. | the maintainer | "The preflight says `<file>` differs from the installed sidecar's template. Please run the lokf-sidecar repair, or confirm the edit is deliberate." |
| `session` | Whether a person is present, or the run is automated. | Unattended: the curator's review session. | nobody | Nothing to send; an automated run is meant to stop there. |
| `network` | Whether PyPI is reachable, and whether `curl` exists. | Version checks, skill installs, and the signing-key identity route. | the maintainer | "This machine cannot reach pypi.org (or has no `curl`). Please allow it, or tell me the version of `lokf` to pin." |

Three things the note need not explain: the preflight changes nothing and is safe to run again; `ok` lines need no action; and a `missing` line is a fact about this machine, not about the person. A repository's own conventions may add rows here; the repository contract checks that every line the preflight can print as missing or a warning has one.
